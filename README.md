# 📖 أداة سحب وترجمة رواية Reverend Insanity (القس المجنون)

أداة بايثون متكاملة ومؤتمتة لسحب فصول رواية **Reverend Insanity** (Gu Zhen Ren) من موقع `novelfire.net` وترجمتها إلى **اللغة العربية الأدبية الفصحى البليغة** باستخدام **Kilo AI Gateway API**.

---

## 🌟 المميزات الرئيسية

1. **سحب ذكي وتنظيف المحتوى (Smart Scraper):**
   - سحب الفصول وتنظيف الإعلانات والتحذيرات الترويجية تلقائياً.
   - استخراج العناوين الأصلية وتتبع الفصول بدقة.
   - حماية ضد أخطاء 404 وتجربة روابط بديلة تلقائياً.

2. **ترجمة أدبية عالية البلاغة (High Literary Arabic):**
   - برومبت مخصص ومعاير لروايات الفانتازيا الصينية والزراعة (Xianxia/Cultivation).
   - قاموس مصطلحات موحد لأهم شخصيات ومفاهيم الرواية (فانغ يوان، زيز الربيع والخريف، الجوهر البدائي، الفتحة الروحية، عشيرة غو يوي، إلخ).
   - تقسيم الفصول الطويلة (Smart Chunking) لضمان عدم اقتطاع الترجمة.

3. **حماية من الحظر وإدارة الأخطاء:**
   - فاصل زمني قابل للتعديل (افتراضياً 20 ثانية) بين الطلبات.
   - نظام إعادة محاولة ذكي (Exponential Backoff) عند حدوث ضغط (429) أو بطء في الخادم.

4. **نظام استئناف ذكي (Resume Support):**
   - حفظ حالة التقدم في `output/progress.json`.
   - إمكانية إيقاف الأداة وإعادة تشغيلها في أي وقت، حيث ستتجاوز الفصول المكتملة مسبقاً تلقائياً.

5. **أداة دمج الفصول في كتاب كامل:**
   - سكربت `compile_novel.py` لدمج كل الفصول المترجمة في ملف واحد (`Reverend_Insanity_Arabic_Complete.md`).

## 🚀 التثبيت والتشغيل

### 1. تثبيت المتطلبات
تأكد من وجود Python 3.8+ ثم قم بتثبيت المكتبات:
```bash
pip install -r requirements.txt
```

### 2. ضبط الإعدادات (اختياري)
تم تضمين الإعدادات الافتراضية ومفتاح الـ API في ملف `.env`. يمكنك تعديل أي قيمة مثل النموذج المستخدم أو وقت التأخير:
```env
KILO_API_KEY=your_key_here
KILO_MODEL=poolside/laguna-s-2.1:free
REQUEST_DELAY_SECONDS=20
```

## 💻 أمثلة الاستخدام عبر سطر الأوامر (CLI)

### 1. تشغيل الترجمة للفصول من 1 إلى 10 (افتراضي)
```bash
python main.py --start 1 --end 10
```

### 2. سحب وترجمة حتى الفصل 2000 مع فاصل زمني مخصص (مثلاً 15 ثانية):
```bash
python main.py -s 1 -e 2000 -d 15
```

### 3. وضع السحب فقط (تنزيل الفصول الإنجليزية دون ترجمة):
```bash
python main.py -s 1 -e 50 --raw-only
```

### 4. وضع الترجمة فقط (ترجمة الفصول المحفوظة مسبقاً دون اتصال بموقع الرواية):
```bash
python main.py -s 1 -e 50 --translate-only
```

### 5. إعادة ترجمة فصول سابقة وتخطي سجل الإكمال:
```bash
python main.py -s 1 -e 5 --force
```

### 6. دمج جميع الفصول المترجمة في ملف كتاب موحد:
```bash
python compile_novel.py
```
