## ⚡ المنظومة البرمجية والأدوات المتاحة

### 1. 🚀 محرك الترجمة المتوازية الفائق (`parallel_translator.py`)
يترجم الفصول بالتوازي عبر فتح 15-20 مساراً متزامناً (Threads) بمعدل **10 فصول كل 15 ثانية**، مع تطبيق قاموس الرواية والفصل التلقائي للفقرات.
```bash
# تشغيل الترجمة بـ 20 مساراً متوازياً:
python parallel_translator.py --start 1 --end 2334 --workers 20
```

### 2. 🤖 أداة استخراج وبناء القواميس تلقائياً (`auto_glossary.py`)
تقوم بتحليل النصوص الإنجليزية لأي رواية جديدة، واستخراج أسماء الشخصيات والتقنيات والعشائر المتكررة، وتوليد ترجمة عربية وصوتية دقيقة وموحدة لها وحفظها في ملف `JSON`.
```bash
python auto_glossary.py
```

### 3. 🌍 خط إنتاج وترجمة أي رواية في العالم (`universal_novel_pipeline.py`)
أداة عامة لسحب وترجمة أي رواية من الإنترنت بضغطة زر واحدة:
```python
from universal_novel_pipeline import UniversalNovelPipeline

# مثال: ترجمة رواية Shadow Slave
pipeline = UniversalNovelPipeline("shadow-slave")
pipeline.run_sample_test(start=1, end=50)
```

### 4. 🩺 نظام الترميم والإصلاح الذاتي للفصول (`auto_healer.py`)
يقوم بفحص الفصول المترجمة، واكتشاف أي فقرات سقطت أو عناوين غير مترجمة، ثم **إعادة ترجمة وترميم تلك الفقرات التالفة فقط في مكانها** دون إعادة ترجمة الفصل كاملاً.
```bash
python auto_healer.py
```

### 5. 🔍 فاحص الجودة الآلي (`audit_quality.py`)
فحص إحصائي يقارن عدد الفقرات بالاصل الإنجليزي، ويفحص الكلمات الأجنبية المتبقية، ويعطي تقييماً رقمياً لجودة كل فصل.
```bash
python audit_quality.py
```

### 6. 📊 فاحص الجودة الذكي فائق السرعة (`smart_quality_evaluator.py`)
فاحص ذكي يقيم الفصول الـ 2,334 في 38 ثانية فقط بمعدل 61 فصلاً/ثانية عبر 6 مقاييس جودة متقدمة دون الحاجة لتحميل نماذج ثقيلة.
```bash
python smart_quality_evaluator.py
```

### 7. 📖 مستخرج القاموس الفانتازي الشامل (`extract_full_glossary.py`)
يستخرج ويوثق أكثر من 500 مصطلح فانتازي ومسار زراعي ومبجل واسم شخصية من نصوص الرواية كاملة ويحفظها في `glossary.json`.
```bash
python extract_full_glossary.py
```

### 8. 🩺 مرمم ومطور الجودة التلقائي (`quality_healer.py`)
يرمم الفقرات الإنجليزية الساقطة، ويوحد المصطلحات الفانتازية، ويعيد بناء العناوين المشوهة.
```bash
python quality_healer.py --auto-flagged
```

### 9. 📈 أداة مقارنة التطور وحساب الفوارق (`compare_evaluations.py`)
تقارن حالة الجودة قبل وبعد عمليات الترميم وتولد جدول مقارنة إحصائي تفصيلي يوضح نسبة التحسن وصافي الفروق.
```bash
python compare_evaluations.py
```

## 🤖 خط الأتمتة السحابي على GitHub Actions (`quality_improvement_pipeline.yml`)

تم تجهيز **Workflow مؤتمت على GitHub Actions** يعمل سحابياً بضغطة زر أو دورياً:
1. **استخراج القاموس الفانتازي** وتحديث المصطلحات من كل الفصول.
2. **فحص الجودة الأساسي** وتسجيل درجات كل فصل.
3. **الترميم التلقائي** لأي فصول تحتوي على فقرات إنجليزية أو مصطلحات ناقصة.
4. **إعادة التقييم الشامل** وقياس الفوارق ونسبة التطور (+Delta).
5. **تحديث ملف الرواية الموحد** وكتاب الماستر.
6. **Commit & Push تلقائي** للفصول المحسنة والتقارير مباشرة إلى المستودع.

### 🎮 كيفية تشغيل الـ Workflow من GitHub:
1. اذهب إلى تبويب **Actions** في المستودع.
2. اختر **"Reverend Insanity Quality Improvement Pipeline"**.
3. اضغط على **"Run workflow"** واختر نمط التشغيل (`full` للتحسين الشامل، أو `heal_flagged` لترميم الفصول المرصودة فقط).
